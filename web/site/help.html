Help

Finding your Canvas calendar link

  1. Sign in to Canvas in a web browser (not the app).
  2. Open Calendar from the left-hand menu.
  3. At the bottom right, click Calendar Feed.
  4. Copy the whole link. It ends in .ics.

Phone notifications (ntfy)

  1. Install the free ntfy app from the App Store or Google Play.
  2. Tap +, paste the topic shown on your Canvas Reminder setup page, and tap Subscribe. Leave the server as ntfy.sh.
  3. Allow notifications when your phone asks.
  4. Back on Canvas Reminder, press Send a test.

Your topic is a long random name that only you know. Don't share it: anyone with it can see your reminders.

Apple Reminders (iPhone Shortcut)

Apple doesn't let websites add to Reminders directly, so a Shortcut on your iPhone fetches your upcoming assignments and adds them for you.

  1. On your dashboard, open Where you're reminded, tick Apple Reminders, and press Create my Shortcut token. Keep that page open.
  2. In the Reminders app, create a list called Canvas.
  3. In the Shortcuts app, tap + and name it Canvas Reminders.
  4. Add Get Contents of URL. Paste the feed address from the setup page. Tap Show More, then under Headers add Authorization with the Bearer … value from the setup page.
  5. Add Get Dictionary Value: get Value for items.
  6. Add Repeat with Each. Inside it:
    1. Get Dictionary Value tag from Repeat Item, then Find Reminders where Notes contains it and List is Canvas (limit 1).
    2. If the action of the Repeat Item is delete: Remove Reminders.
    3. Otherwise, if a reminder was found: Edit Reminder to set its Due Date to due and Alert to alert.
    4. Otherwise: Add New Reminder with title, list Canvas, due date due, alert alert and notes notes.
    Turn due and alert into dates with Get Dates from Input.
  7. In Automation, tap + → Time of Day, choose 8:00 am daily, Run Immediately, and pick Canvas Reminders. Add 1 pm and 6 pm too, so alerts move to your next reminder time promptly.

Action names differ slightly between iOS versions (older versions call "Edit Reminder" "Set … of Reminder").

Email reminders

Nothing to set up. If the first email lands in spam, mark it as "not spam" so the rest arrive normally.
